02

Vorschau und Übergabe

Dieses Beispiel zeigt extrahierte JSON-Felder. Der Server prüft sie gegen die Beispielregel. Für Signatur, Ausstellervertrauen und Widerruf nutze einen Guard-Endpunkt, der für das signierte Format eingerichtet ist.

Signiertes Beispiel im Guard öffnen

Der Guard lädt in einem neuen Tab ein separat signiertes Credential. Deine Änderungen bleiben hier.

Gib für jede Beispielprüfung einen Admin-Token mit Zugriff auf alle Endpunkte ein. Beim Start der Prüfung wird das Feld geleert.

Der Guard sendet diesen Inhalt erst, wenn du dort die Prüfung startest.
